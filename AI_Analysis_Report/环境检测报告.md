### 为第二阶段 `flash_jlink.ps1` 预先核实的设计约束

1. **Commander 路径**：`C:\Program Files\SEGGER\JLink_V990\JLink.exe`（V9.90）为首选；旧版 V490 不应使用。
2. **接口/速度**：`SelectInterface SWD`（`si 1`）+ `Speed auto`；仅在连接不稳定时降速（例如 4000 kHz → 1000 kHz）。
3. **固件格式优先级**：优先 `C7Detect.out`（ELF，`LoadFile` 自带段地址，无需猜地址）；若用 `C7Detect.bin`，起始地址必须取 `link_auto_link.icf:9` / `boot.map:41` 的 **0x08000000**，禁止猜测。
4. **芯片型号**：脚本必须先 `Device STM32F103xC` + 实际 `Connect` 读回 IDCODE 并与工程 `.ddf` 交叉核对；**禁止自动切换到其他型号**；未识别到芯片直接失败退出。
5. **VTref 前置门禁**：`ShowHWStatus` 读到 VTref ≤ 0 或明显异常 → 立即非零退出，不执行任何写操作。
6. **校验**：`.bin` 用 `VerifyBin <file>, 0x08000000`；ELF 用 `LoadFile` 返回状态 + 读回校验。完整日志写入 `Build_Logs/`。
7. **禁止项**：`Erase`（整片擦除）、Option Bytes、读/写保护、`Power On` 供电、未知芯片烧录、固件不明确时烧录。
8. **⚠️ Bootloader 冲突（必须先由用户决策）**：现有唯一 BIN 覆盖 `0x08000000` 起的 Bootloader 区。若策略是"不覆盖 Bootloader"，当前工程**没有**单独的 App-only 镜像，需要额外从 `app.bin` / `C7Detect.out` 提取或新增输出配置 —— 这属于工程配置变更，须先请求授权。
